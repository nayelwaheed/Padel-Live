PADEL LIVE — START HERE

TEST ON WINDOWS
1. Extract the ZIP.
2. Open the padel-live-pwa folder.
3. Click the File Explorer address bar, type: powershell
4. Press Enter.
5. Run:

   python -m http.server 8080

6. Open http://localhost:8080 in Chrome or Edge.

PUBLISH THE APP
Upload the root app files to your existing GitHub Pages repository. GitHub Pages provides the HTTPS address needed for the iPhone Home Screen web app.

INSTALL ON IPHONE
1. Open your GitHub Pages link in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Tap Add.
5. Open Padel Live from its Home Screen icon.

AUTOMATIC DATA REFRESH
Read server/SERVER_SETUP.md. It walks through creating the backend, storing the API token privately, and connecting the app by editing config.js.
