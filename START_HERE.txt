PADEL LIVE — START HERE

You do NOT need to install Node, Expo, Xcode, or any paid software for this version.

FIRST: TEST IT ON YOUR WINDOWS COMPUTER
1. Extract the ZIP.
2. Open the extracted padel-live-pwa folder.
3. Click the address bar in File Explorer, type: powershell
4. Press Enter.
5. In the blue/black window, type:

   python -m http.server 8080

6. In your browser, open:

   http://localhost:8080

If Windows says Python is not installed, you can skip local testing and go straight to GitHub Pages, or install Python free from python.org.

SECOND: PUT IT ONLINE FOR FREE
Use the detailed steps in README_FIRST.md to upload it to GitHub Pages. GitHub Pages gives you the HTTPS web address required for an installable iPhone web app.

THIRD: INSTALL ON YOUR IPHONE
1. Open your GitHub Pages link in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Tap Add.
5. Open Padel Live from its Home Screen icon.
